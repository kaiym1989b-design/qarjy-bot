# 💰 Қаржы боты (Telegram, қазақ тілінде)

Кіріс-шығысты еркін мәтінмен жазады, ай сайынғы міндетті төлемдерді еске салады,
әр күні «айдың соңына дейін тағы қанша табу керек» екенін айтып тұрады.

## Не істей алады

| Команда | Не істейді |
|---|---|
| `5000 такси`, `50к азық-түлік`, `+200000 жалақы` | Транзакцияны жазады (командасыз). «↩️ Болдырмау» батырмасы бар |
| `/balance` | Осы айдағы кіріс, шығыс, баланс, категориялар бойынша бөлініс |
| `/obligations` | Міндетті төлемдерді қосу / өңдеу / өшіру |
| `/settings` | Күнделікті шолу сағатын таңдау (6:00–23:00) |
| `/cancel` | Басталған әрекетті тоқтату |

**Автоматты хабарламалар (Алматы уақытымен):**
- Әр күні таңдаған сағатта — шолу: тапқаның, шығыс, міндетті төлемдер, «тағы табу керек».
- Төлем күніне 7, 2 күн қалғанда және сол күні — жеке ескерту (күндерді өзгертуге болады).
- Жексенбі 19:05 — қаржылық сауаттылық кеңесі (7 кеңес айналып тұрады).

**«Тағы табу керек» қалай есептеледі:** `міндетті төлемдер сомасы − осы айдағы кіріс`
(0-ден төмен болса — «жабылды» дейді). Күнделікті шығыстар бұған қосылмайды,
сондықтан квартираны «150000 квартира» деп шығысқа жазсаң да, екі рет есептелмейді.

## Құрылымы

```
main.py            — іске қосу
config.py          — .env оқу
db/schema.sql      — кестелер (users, obligations, transactions)
db/repo.py         — барлық SQL сұраулары (async)
handlers/          — командалар мен батырмалар
services/parser.py — «50к кофе» сияқты мәтінді тану
services/reminders.py — күнделікті/апталық хабарламалар
services/reports.py   — баланс пен шолу мәтіндері
tests/             — 52 тест
```

## 1. Дайындық

1. **Бот токені:** Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → токенді көшір.
2. **Supabase:** жоба құр → жоғарыдағы **Connect** батырмасы → **Session pooler** жолын көшір
   (`...pooler.supabase.com:5432/...`). `[YOUR-PASSWORD]` орнына дерекқор құпиясөзін қой.
   > Direct connection (`db.xxx.supabase.co`) жолы тек IPv6 арқылы жұмыс істейді, Railway-ден қосылмауы мүмкін — Session pooler қолдан.
3. Кестелер бот алғаш қосылғанда **өзі құрылады** (`db/schema.sql`). Қаласаң, оны Supabase → SQL Editor-ге қолмен қойып та жүргізуге болады.

## 2. Компьютерде іске қосу

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env               # сосын .env ішін толтыр
python -m pytest                   # тесттер
python main.py                     # бот қосылды → Telegram-да /start
```

## 3. Railway-ге деплой

1. Жобаны GitHub-қа жүкте (`.env` `.gitignore`-да тұр — жария болмайды).
2. Railway → **New Project → Deploy from GitHub repo** → осы репоны таңда.
3. **Variables** бөліміне екеуін қос: `BOT_TOKEN` және `DB_PASSWORD` (Supabase дерекқор құпиясөзі).
   Толық жолды құрастыру керек емес — бот оны өзі жасайды. Қаласаң, оның орнына толық `DATABASE_URL` беруге де болады.
4. Railway `Procfile`-дағы `worker: python main.py` процесін өзі қосады.
5. **Deploy Logs**-та `Бот іске қосылды ✅` жазуын күт → Telegram-да `/start`.

> ⚠️ Ботты бір уақытта тек **бір жерде** қос (не компьютерде, не Railway-де). Екеуі қатар жүрсе, Telegram `Conflict` қатесін береді.

## Парсерді жетілдіру

Категориясы танылмаған жазбалар логқа `UNCATEGORIZED: '...'` деп түседі.
Бір аптадан кейін Railway логын қарап, жиі кездесетін сөздерді
`services/parser.py` ішіндегі `CATEGORIES` тізіміне қос, сосын `python -m pytest`.

## Қауіпсіздік

- Токен мен құпиясөз тек `.env` / Railway Variables-та.
- Кестелерде RLS қосулы — Supabase-тің жария API-і арқылы деректерге ешкім кіре алмайды.
- Әр қолданушы тек өз жазбаларын көреді/өзгертеді (барлық сұрауда `user_id` тексеріледі).
